# جلساتي

لوحة محلية لتصفح جلسات Claude Code ومراجعتها كل يوم.

## التشغيل
- انقر مرتين على `جلساتي.command`، أو شغّل `npm start` ثم افتح http://localhost:4477
- لا تحتاج أي مكتبات خارجية. تعمل بـ Node 20 أو أحدث.

## المميزات
- الجلسات مجمّعة حسب اليوم. الجلسة التي امتدت عدة أيام تظهر في كل يوم عملت فيه.
- عروض: اليوم، أمس، آخر 7 أيام، كل الجلسات، المثبّتة، تحتاج متابعة، مكتملة.
- قائمة المشاريع مرتبة حسب آخر نشاط.
- بحث في العناوين والطلبات والملخصات والملاحظات (اختصار `/`).
- ملخص ذكي لكل جلسة: ما أُنجز، وما بقي معلّقًا، والخطوة التالية. يولّده أمر `claude` المحلي بلا مفتاح API.
- حالة لكل جلسة، وتثبيت، وملاحظات خاصة بك.
- زر يستأنف الجلسة في نافذة Terminal جديدة.
- لوحة المفاتيح: `j`/`k` للتنقل، `Enter` للفتح، `Esc` للإغلاق.

## البيانات
- يقرأ من `~/.claude/projects` ولا يعدّل أي ملف هناك.
- الفهرس والملخصات والملاحظات محفوظة في `data/` (خارج git).
- نموذج التلخيص الافتراضي `haiku`، ويمكن تغييره: `SUMMARY_MODEL=sonnet npm start`
